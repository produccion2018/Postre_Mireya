# Mireya's Sweet Redesign

PROYECTO: POSTRES MIREYA
Quiero realizar un rediseño completo y profesional del frontend existente del proyecto "Postres Mireya".
IMPORTANTE:
Este proyecto ya existe y tiene una estructura, imágenes, páginas, estilos, JavaScript y funcionalidades. Antes de modificar cualquier cosa, analiza cuidadosamente el proyecto existente y reutiliza todo lo que sea útil.
NO quiero que simplemente crees una página nueva desde cero ignorando el proyecto actual.
La intención es transformar el proyecto existente en una web moderna, elegante, cálida y profesional para una marca personal de repostería llamada:
POSTRES MIREYA
El resultado debe parecer una página web profesional de una emprendimiento real de repostería, no una plantilla genérica ni una página creada automáticamente por IA.
==================================================
1. OBJETIVO GENERAL
==================================================
Rediseñar completamente la experiencia visual del sitio manteniendo la identidad de Postres Mireya.
El sitio debe transmitir:
- repostería artesanal
- calidez
- elegancia
- cercanía
- dulzura
- trabajo artesanal
- personalidad
- confianza
- calidad
Debe ser visualmente atractivo para mostrarlo como DEMO.
No quiero un diseño SaaS.
No quiero una interfaz fría.
No quiero que parezca una plantilla genérica.
Quiero que parezca una marca real de repostería con identidad propia.
==================================================
2. ANALIZAR PRIMERO EL REPOSITORIO
==================================================
Antes de modificar el proyecto:
- revisar la estructura existente
- revisar index.html
- revisar CSS
- revisar JavaScript
- revisar páginas existentes
- revisar navegación
- revisar carrito si existe
- revisar imágenes
- revisar nombres de productos
- revisar funcionalidades existentes
- revisar cómo están organizadas las imágenes
- revisar las rutas existentes
Conservar las funcionalidades que ya funcionan siempre que sean compatibles con el nuevo diseño.
No eliminar páginas o funcionalidades existentes sin analizar primero su propósito.
==================================================
3. NO CREAR BACKEND
==================================================
NO crear backend.
NO crear base de datos.
NO crear autenticación.
NO crear APIs nuevas.
NO migrar la aplicación a otro backend.
NO implementar servicios externos innecesarios.
Si actualmente existe alguna funcionalidad de carrito, pedido o navegación, mantenerla funcionando en frontend.
El objetivo de esta etapa es principalmente:
REDISEÑO + UX + UI + PRESENTACIÓN + RESPONSIVE.
Posteriormente nosotros podremos modificar o conectar funcionalidades reales.
==================================================
4. IDENTIDAD VISUAL
==================================================
La identidad visual debe partir de la estética actual del proyecto y especialmente del uso del color ROSA.
Mantener el rosa como color principal de la marca, pero hacerlo más elegante y profesional.
Utilizar una paleta relacionada con:
- rosa
- rosa suave
- blanco
- crema
- tonos neutros
- gris para determinadas áreas
No convertir toda la página en rosa.
El rosa debe funcionar como identidad y acento.
El footer debe tener especialmente un tratamiento en tonos GRISES.
==================================================
5. TIPOGRAFÍA — MUY IMPORTANTE
==================================================
La tipografía es una prioridad absoluta.
NO utilizar una tipografía genérica que haga que el sitio parezca generado por IA.
Elegir una combinación tipográfica con personalidad propia y adecuada para una marca artesanal de repostería.
La tipografía debe transmitir:
- elegancia
- dulzura
- cercanía
- personalidad
- calidad artesanal
Utilizar como máximo dos familias tipográficas:
1. Una tipografía principal para títulos, frases destacadas y elementos de marca.
2. Una tipografía secundaria para navegación, textos y contenido.
Puede utilizarse una tipografía serif elegante para títulos combinada con una sans-serif moderna para textos.
IMPORTANTE:
La jerarquía tipográfica debe estar muy cuidada:
- títulos principales
- subtítulos
- textos
- botones
- navegación
- precios
- nombres de productos
- descripciones
No utilizar demasiados estilos tipográficos.
La tipografía debe hacer que Postres Mireya tenga una identidad visual reconocible.
==================================================

POSTRES MIREYA
No inventar un logo completamente diferente.
Dejar el sistema preparado para que posteriormente podamos colocar el logo definitivo proporcionado por nosotros.

Mostrar otra frase breve relacionada con los productos.

- permitir navegación manual
- tener indicadores
- funcionar correctamente en móvil
- utilizar imágenes optimizadas
No hacer transiciones exageradas.
